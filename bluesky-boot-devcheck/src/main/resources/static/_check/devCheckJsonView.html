검색 문법

foo
키 또는 값에 foo가 포함된 항목 (대소문자 무시)
key:value
키에 key가, 값에 value가 포함된 항목(부분 일치). 공백·따옴표는 무시 — moduleName : "crypto" = moduleName:crypto
key:
값은 보지 않고 키만 검색 (뒤에 콜론만) — lin:
A > B
A에 해당하는 항목 아래 전체에서 B를 찾음(깊이 무관). 여러 단계도 가능 — A > B > C:D
A >> B
A 바로 아래(직계) 항목만 대상 — modules >> lin = modules의 자식 키 중 lin 포함
예시(클릭):
검색 중 ⊞ 결과 하위 펼치기를 누르면 매칭된 항목의 하위 전체를 펼쳐볼 수 있습니다. Ctrl+F로 검색창 이동, Enter로 즉시 검색.
